    Invariant-Aware Harness Enforcement to Protect LLM Agents from Silent API Failures

    LLM agent通过调用API并信任返回结果来回答问题。API可能发生静默失败：忽略请求的部分内容（如命名错误的过滤器），但返回HTTP 200和看似合理的错误结果。现有修复方案（检查清单、审查模型、LLM判断器）让模型自行发现问题，但模型往往看到问题后仍继续作答。SilentGuard将决策权从模型转移出去，通过不变量感知的harness enforcement在系统层面拦截此类失败。

    为什么重要
    静默API失败是生产环境agent pipeline中难以检测的可靠性问题。SilentGuard提出的系统层拦截思路对构建鲁棒agent harness具有直接工程价值，优于依赖模型自检的软件方案。

    Jetriever: Shifting Agent Memory Retrieval from Similarity to Utility

    传统agent记忆检索依赖相似度搜索，但有用的记忆不一定与当前问题相似。Jetriever将每条存储记忆按其对当前问题的决策效用（Jev's decision score）排序，替代相似度搜索，实现全池效用评分。在InMind的125个间接查询任务上，金标准交换首位准确率达84.8%，显著优于BM25和MiniLM基线。
