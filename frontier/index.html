    Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression

    研究发现，分块 KV-cache 压缩在引入「相位」这一新坐标的同时，导致模型性能对 token 在压缩窗口内的相对位置产生系统性不对称——即「周期性弱点」。同样的 token 因其在压缩块中的位置不同，模型表现出现明显差异。
