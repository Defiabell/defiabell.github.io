    FlyingStart: Learned Cross-Token Warm Starts for Fixed-Point Decoding in Recurrent-Depth Language Models

    循环深度语言模型（如 Looped Transformer）每个 token 均从随机噪声出发迭代至收敛，成本高昂。FlyingStart 通过学习跨 token 的「热启动」初始化，将上一 token 的收敛状态作为下一 token 迭代起点，显著减少所需迭代步数，降低解码延迟。
