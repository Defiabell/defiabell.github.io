我做的工具

从日常的小麻烦开始，做一些自己愿意一直用的东西。这里放用途、入口和限制；具体安装步骤以各项目的说明为准。

一息

打开 App 之前，先停十秒。

用网页和 iPhone 快捷指令，在打开小红书等 App 前留出一次呼吸的时间，再决定是否继续。「今日」页面则放下当前最重要的事，默认三件，可以调整。

拦截需要在 iPhone 上配置个人自动化；它是一道可以主动跨过的停顿，不是强制锁机。

shotsync

电脑发图片，手机接着用。

直接注册即可在设备之间传图片和文字，支持手机主屏幕入口、分享和批量删除。也可选择部署到自己的 Cloudflare。

在线版限100个账号试用，新账号默认保留7天，有用量限制，文件存放在运营方的 Cloudflare；重要文件请另行备份。

Day Monitor

看见一天的时间去了哪里。

macOS 菜单栏工具，定时截图并交给模型识别活动，生成时间线、分类和日报。浏览器演示使用示例数据。

需要截图权限和兼容的模型服务；使用云端模型时截图会发送给该服务。本地模型需要自行配置。

  • 下载与使用说明 ↗

Reading Room

把散落的本地文档放到一张阅读桌上。

在同一个窗口阅读不同文件夹里的 Markdown、HTML 和 PDF，不需要导入资料库。适合查看笔记、项目文档和 Agent 生成的报告。

只读，不提供编辑、同步或知识图谱；搜索直接读取文件，大目录的首次加载会更慢。
